# Session Log: 2025-01-16

## Summary

Scaffolded a new open-source Cloudflare Worker project to sync Basecamp cards to GitHub issues.

## Decisions Made

### Architecture
- **Trigger**: Manual via Web UI (user pastes Basecamp card URL, selects repo)
- **Sync direction**: One-way (Basecamp → GitHub)
- **Hosting**: Cloudflare Workers with KV storage
- **Auth**: GitHub App (existing), Basecamp OAuth token

### Sync Behavior
- **Comments**: Sync from Basecamp to GitHub (one-way)
- **Card edits**: Sync title/content updates to GitHub issue
- **Status changes**: Not synced (managed independently)

### Mapping Strategy
- Single Basecamp project may have multiple repos
- User selects target repo when linking via Web UI
- Mapping stored in Cloudflare KV: `card:{projectId}:{cardId}` → `{repo, issueNumber, linkedAt}`
